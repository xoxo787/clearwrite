윤문 결과가 나오면 글자 차이로 계산합니다.

공백 포함 · (삭제·교체된 원문 글자 + 추가·대체된 글자) ÷ (원문 + 수정본 글자 수)

문체 점수는 검증되지 않은 참고용 평가이며 AI 작성 확률·작성률이나 저자 판정이 아닙니다. 네 항목별 0~25점을 합산합니다. 실제 수정 비율은 이번 윤문의 변경량으로, 기존 글의 AI 작성 여부를 뜻하지 않습니다.
