# 보안 정책과 실제 보장 범위

## 기본 경계

기본 `builtin`, `analyze`, `prepare`, `apply`, `verify`는 Python 표준 라이브러리만 사용하고 네트워크에 연결하지 않습니다. 임의 코드 실행, 텔레메트리, API 키 수집, 자동 패키지·모델 설치가 없습니다. 원문은 데이터이며 `eval`, shell interpolation, 모델의 도구 호출에 사용하지 않습니다.

독립 프로그램은 원본 파일을 덮어쓰지 않습니다. 기존 출력 교체에는 `--force`가 필요합니다. 출력 파일의 심볼릭 링크를 거부하며, 신규 파일은 배타 생성하고 교체는 임시 파일과 원자적 rename을 사용합니다. 경로의 상위 폴더는 사용자가 신뢰하는 위치여야 합니다. 사용자가 명시한 경로의 읽기/쓰기를 제한된 sandbox로 격리하는 프로그램은 아닙니다.

## 입력과 편집 계획

본문 최대 12,000자, JSON 최대 2MB, 편집 최대 80개로 제한합니다. 중복 JSON 키, NaN/Infinity, 잘못된 Unicode, 제어 문자, 범위를 벗어난 위치, 겹치는 편집, 원문 해시 불일치는 거부합니다. 인용·코드·링크·표·YAML·지정 용어를 보수적으로 보호합니다. 숫자·단위·순서·일부 부정/가능성/조건/의무/비교/증감 표지를 전후 및 편집 단위에서 비교합니다. 검사를 통과하지 못하면 기본적으로 원문 전체로 되돌립니다.

이 검사는 모든 고유명사·사실·관계·수학 표현의 의미를 이해하지 못합니다. `A는 좋고 B는 나쁘다`에서 주체를 바꾸는 편집처럼 문자 변화가 작아도 의미가 바뀌는 경우를 놓칠 수 있습니다. 이 한계는 `semantic_equivalence: not_established`로 항상 출력합니다. 채용·징계·평가·학술 부정행위 판단에 AI 문체 점수를 사용하지 마세요.

## 로컬 웹 화면

서버는 `127.0.0.1`에만 바인딩합니다. 정확한 Host/Origin 검사, 세션별 무작위 CSRF 토큰, CSP nonce, no-store, 프레임 삽입 차단, textContent 기반 렌더링을 사용합니다. 임의 파일 읽기 API, CORS 허용, CDN, 원문 요청 로그는 없습니다. 모델 윤문·문체 분석 버튼에는 매번 전송 동의가 필요합니다. HTTP 본문은 100KB까지 허용합니다. 작업은 최대 2개까지 처리하고 서버 기록은 최대 24개까지 보관합니다. 완료·실패·취소 기록은 작업이 끝난 시점부터 15분 뒤 백그라운드 정리기로 자동 삭제합니다(일반적인 실행 중 최대 약 1초의 정리 주기). 조회할 때도 만료를 검사하므로 만료된 기록을 다시 반환하지 않습니다. 진행 중인 요청은 이 보관 기한으로 삭제하지 않습니다. 앱 종료 시 기록을 비우고 실행 중 작업을 취소하며, 늦게 도착한 응답으로 기록이 복구되지 않도록 합니다. 브라우저에 열어 둔 원문·수정본과 사용자가 저장한 파일은 이 서버 기록 정리의 대상이 아닙니다. 공개 서버·다중 사용자·신뢰할 수 없는 로컬 프로세스에 대한 서비스가 아닙니다. reverse proxy로 인터넷에 노출하지 마세요. 브라우저 확장 프로그램과 같은 로컬 악성 소프트웨어까지 방어하지 못합니다.

## 선택 기능의 전송 범위

| 경로 | 보내는 곳 | 데이터 | 조건 |
|---|---|---|---|
| 기본 Python 처리 | 없음 | 없음 | 기본값 |
| Codex/ChatGPT 스킬 | 현재 호스트의 모델 환경 | 원문·편집 지침·문체 예시 | 사용 환경의 모델/권한 정책 적용 |
| Codex/Claude CLI 편집기 | 설치된 CLI가 연결하는 OpenAI/Anthropic 서비스 | 원문·편집 지침·선택 문체 예시 | 매번 전송 동의, CLI 로그인과 사용량 |
| Ollama | 고정 `127.0.0.1:포트` | 원문·지침·선택한 문체 예시 | `--backend ollama` 선택 |
| Codex/Claude 문체 분석 | 설치된 CLI가 연결하는 OpenAI/Anthropic 서비스 | 원문·실제 수정본·평가 지침 | 매번 전송 동의, CLI 로그인과 사용량 |

Ollama 어댑터는 cloud가 들어가는 모델명, 프록시, 리디렉션을 거부하고 모델을 다운로드하지 않습니다. 그래도 로컬 서버 자체가 변조되었거나 뒤에서 외부 서비스를 호출하면 이 프로그램은 이를 증명할 수 없습니다. 로컬 서버의 신뢰성은 사용자가 관리해야 합니다.

웹 UI는 Ollama를 사용하지 않습니다. Codex CLI는 ignore-user-config/ephemeral/read-only와 호출별 도구·플러그인·MCP·프로젝트 지침 제한을 사용합니다. Claude는 bare/print, 빈 도구/MCP 설정과 세션 저장 제외를 사용합니다. 필요한 옵션이 없는 CLI는 거부합니다. 0.3.1부터 원문·응답·stderr는 크기를 제한한 stdin/stdout/stderr 파이프로 주고받으며 ClearWrite가 내용 파일을 만들지 않습니다. Codex는 `--json` 이벤트 중 최종 `agent_message`를 읽고, Claude는 stdout의 JSON 응답을 읽습니다. 임시 작업 폴더에는 개인정보가 없는 고정 응답 스키마만 기록합니다. 따라서 강제 종료로 폴더가 남더라도 ClearWrite가 기록한 원문·응답 파일은 없습니다. 이 변경은 구버전의 잔여 파일이나 CLI 자체의 파일을 소급 삭제하는 기능이 아닙니다. 메모리·스왑·운영체제 덤프의 완전 소거를 보증하지 않습니다. 기본 제한 시간은 180초(최대 300초), 출력은 2MB입니다. 취소는 해당 프로세스 트리만 중단하지만 이미 서버에서 소비한 사용량을 취소하지는 않습니다. 인증 파일을 읽거나 전역 권한을 변경하지 않습니다. CLI 자체의 캐시·공급자 보관은 해당 도구의 정책을 따릅니다. 설치된 CLI와 로컬 OS의 신뢰가 전제입니다.

문체 분석은 원문·실제 수정본의 해시와 정확한 인용, 항목별 점수 범위를 검증합니다. 응답을 HTML로 삽입하지 않습니다. 이 검증은 모델의 판단이 사실이라는 보증이 아닙니다. 오류·취소 시 점수를 생성하지 않으며 기존 윤문 결과를 유지합니다. Pangram API 연결·키 조회·전송 코드는 0.3.0에서 제거했습니다.

## 설치·공급망

설치기는 `--apply` 없이는 변경 계획만 출력합니다. 자기 스킬/플러그인 폴더와 마켓플레이스의 자기 항목 외에는 수정하지 않습니다. 전역 `AGENTS.md`, shell profile, Codex 권한 설정, config.toml, 인증 정보는 변경하지 않습니다. `--replace` 교체는 기존 자기 폴더를 백업합니다. 심볼릭 링크를 통한 설치 경로 우회를 거부합니다.

번들 소스는 `scripts/build_bundles.py`로 생성하며 파일 해시 동기화 테스트가 있습니다. 실행 의존성은 0개입니다. 패키지 빌드는 setuptools를 사용하고, CI의 GitHub Actions와 선택 모델/API는 별도 공급망입니다. 이 문서는 독립 보안 감사나 침투 테스트 완료를 의미하지 않습니다. 최초 개발 환경의 테스트 범위는 `reports/VALIDATION.md`에 기록합니다.

## 비공개 자료와 신고

검수 JSON에는 결과 글과 원문 일부, 수정 계획이 포함됩니다. `.clearwrite-runs/`에서 작업하고 실사용 자료를 공개 저장소에 커밋하지 마세요. `.gitignore`는 예방책일 뿐 이미 추적된 파일이나 임의 위치의 비밀 자료를 찾아내는 보안 제품이 아닙니다.

공개 저장소를 만들면 GitHub의 비공개 취약점 신고를 활성화하는 것을 권장합니다. 보안 문제에는 실제 비밀키·개인정보를 첨부하지 말고 최소 재현 예문을 사용하세요. 아직 발급하지 않은 보안 연락처나 운영 SLA를 만들어 표기하지 않습니다.
