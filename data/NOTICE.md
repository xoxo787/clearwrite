# 비교 자료의 출처와 권리

## 구분

`human_historical` 4개는 생성형 AI 이전에 발표된 작가의 저작물을 현재 웹 전사본에서 가져왔습니다. 전사 오류나 후대 편집 가능성은 남아 있습니다. `human_reference` 4개는 Python 문서의 사람 편집 참고군입니다. 현재 페이지를 편집한 모든 기여자의 AI 사용 여부까지 검증한 것은 아닙니다. 따라서 8개 모두를 법의학적으로 인증된 현대 사람 문장으로 표시하지 않습니다.

`ai_generated` 8개와 `stress_fixture` 4개는 개발 대화에서 새로 생성했습니다. 가상의 이야기와 예시이며 실제 사용 경험이나 연구 결과가 아닙니다. 이 프로젝트 배포자는 가능한 범위에서 MIT 조건으로 함께 제공합니다. AI 산출물의 저작권 성립 자체를 보장하지 않습니다.

## Python 문서

원문 및 한국어 번역의 권리자는 Python Software Foundation과 기여자입니다. `licenses/PSF-2.0.txt`의 고지를 유지하세요. 원문의 링크/HTML 표시를 제거하고 문단을 발췌했습니다. 글의 의미를 수정한 출력이 있는 경우 개별 전후 기록에 변경 사항이 있습니다. 원문이 3.9 문서라고 해서 현행 Python 사용법을 권장하는 것은 아닙니다. 문체 비교용 자료입니다.

## 역사적 작품

현진건의 「운수 좋은 날」(1924), 김동인의 「배따라기」(1921), Henry David Thoreau의 Civil Disobedience(1849), Arthur Conan Doyle의 A Scandal in Bohemia(1891)에서 발췌했습니다. 원저작물은 오래된 공개 저작물이며, 배포 지역에 따라 권리 판단은 다를 수 있습니다.

위키문헌 원문은 해당 문서의 퍼블릭 도메인 표시와 원저작물을 기준으로 발췌했으며, 사이트의 안내문·편집 해설 등 CC BY-SA 자료는 가져오지 않았습니다. 웹 전사본의 현대 편집에 별도 권리가 발생하는 지역이라면 그 조건을 추가 검토하세요. 출처 URL을 항상 유지합니다.

Project Gutenberg에서는 원저작물 본문 일부만 사용했습니다. 웹사이트 로고·편집 서문·별도 삽화는 재배포하지 않습니다. Project Gutenberg는 출처 식별이며 후원·인증 표시가 아닙니다. 전체 전자책을 재배포하려면 해당 파일의 Project Gutenberg 라이선스와 상표 조건을 별도로 따르세요. Sherlock Holmes 첫 문단의 장식용 분리 문자 `T o`는 `To`로 이어 적었습니다.

## 파일 무결성과 변경 추적

각 레코드의 sha256은 배포된 UTF-8 원문의 해시이며 웹페이지 전체 HTML의 해시가 아닙니다. 최초 페이지의 변경 불가능한 아카이브가 아니라, 조회한 발췌문의 보관본입니다. 조회일은 2026-10-17입니다. 원문과 편집 출력은 프로젝트의 일반 코드 라이선스만으로 묶지 않습니다.

모든 URL·저자·정규화 방식은 `corpus.jsonl`에 있습니다. `editorial_proposals.jsonl`은 개발 대화에서 작성한 실제 제안이며 별도 API 호출 로그나 전문가의 정답 레이블이 아닙니다.
