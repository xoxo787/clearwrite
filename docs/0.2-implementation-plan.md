# ClearWrite 0.2 로컬 배포 준비

## 목표

글 입력 → 설치된 Codex/Claude CLI로 문맥 윤문 → 보존 검사 → 원문/결과의 변경 표시와 이유를 한 화면에서 확인한다. 기존 Ollama 웹 선택지는 제거한다. 규칙 점수를 AI 작성 확률로 바꾸지 않으며 외부 탐지 결과가 있을 때만 AI 분류 비율을 표시한다.

## 화면 계약

- 대상: 반복적으로 글을 다듬는 한국어 사용자. 1440x900과 390x844에서 검증한다.
- 방향: 종이와 형광펜을 닮은 차분한 편집 도구. 기존의 녹색·크림색을 유지하고 수정 부분에 노란색, 삭제 부분에 분홍색을 사용한다.
- 첫 화면: 원문 입력, Codex/Claude 선택, 전송 동의, 윤문 실행을 바로 노출한다. 우측 결과와 수정 이유 목록은 빈 상태부터 자리를 유지한다.
- 핵심 상호작용: 변경 구간을 선택하면 해당 수정의 원문·결과·이유가 연결된다. 원문을 바꾸면 이전 결과가 오래된 결과임을 표시하고 복사/저장을 막는다.
- 접근성: 44px 이상 조작 영역, 명시적 레이블, 키보드로 수정 선택, 보이는 초점, 상태 알림, 색과 텍스트를 함께 사용한다.

## 상태

| 상태 | 트리거 | 피드백과 다음 행동 |
|---|---|---|
| empty | 입력/결과 없음 | 입력 안내, 외부 요청 없는 예시 체험 |
| loading | 모델/탐지 요청 중 | 실행 중인 제공자와 경과 상태, 취소 |
| permission | 모델/탐지 전송 동의 없음 | 어떤 서비스로 무엇을 보내는지 표시, 동의 후 실행 |
| error | CLI 없음·실패·시간 초과 | 원문 유지, CLI 설치/로그인 또는 다시 실행 안내 |
| partial | 일부 검사 미실행/외부 검사 미완료 | 윤문 결과 유지, 해당 지표만 미측정으로 표시 |
| success | 편집 또는 안전한 변경 없음 | 실제 적용된 변경만 표시, 복사/저장·이유 확인 |

## 구현 순서

1. 기존 0.1.1 소스·검증 엔진을 기준으로 Codex/Claude CLI 어댑터와 취소 가능한 작업을 추가한다.
2. 원문 오프셋과 적용 결과에 근거한 변경 표시 자료를 만들고 인터랙티브 비교 UI를 구현한다.
3. 실제 외부 탐지기 연결을 명시적 동의 뒤에 제공한다. 미실행 값을 추정치로 채우지 않는다.
4. Windows 실행 진입점과 로컬 배포 패키지를 만들고 소스·번들·문서를 동기화한다.
5. 단위/HTTP/실제 브라우저/설치본을 검증한다. 모델 실요청·공개 업로드·발행은 준비된 결과를 제시한 후 별도 승인 단계로 둔다.

## 경계

기존 로그인은 각 CLI가 처리한다. 인증 파일을 앱이 읽거나 복사하지 않는다. 원문은 명령행 문자열이 아닌 표준입력으로 전달한다. 도구·MCP·프로젝트 지침이 개입하지 않도록 실행 옵션을 제한한다. 외부 요청은 사용자 클릭과 전송 동의가 있을 때만 시작한다. 공개 웹 서버로 배포하지 않는다.
