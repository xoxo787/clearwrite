# ClearWrite 0.4.0 실행과 모델 연결

## Windows 사용

배포 ZIP을 **전부 압축 해제**하고 `ClearWrite/ClearWrite.exe`를 실행하세요. `_internal` 폴더도 함께 두어야 합니다. Python 설치는 필요 없습니다. 관리자 권한, 자동 시작 등록, 모델 다운로드는 없습니다. 이 PC 전용 브라우저 화면을 엽니다.

1. `Codex` 또는 `Claude Code`를 선택하고 글을 입력합니다. 필요하면 **편집자 페르소나**(얼마나 과감하게 고칠지)와 **문법 스타일**(합니다체·해요체·한다체)을 고릅니다. 고르지 않으면 지금까지와 같은 '담백한 편집자'로, 원문 종결어미를 유지합니다.
2. 원문 전송에 동의하고 **윤문하기**를 누릅니다.
3. 파란 형광펜과 밑줄은 추가·수정, 붉은 취소선은 기존 표현입니다. 구간이나 오른쪽 설명을 선택하면 원문·수정본·이유 영역이 함께 해당 위치로 이동합니다. 추가·삭제만 있는 자리도 위치 표식으로 이동할 수 있습니다. Enter/Space 및 이전·다음 버튼도 지원합니다. 좁은 화면은 세 영역을 세로로 배치하며, 내부 선택 위치를 함께 맞춥니다.
4. 아래 **실제 수정 비율**에서 글자 변경량을 확인합니다. **AI 문체 분석**은 위에서 선택한 모델로 원문·수정본을 함께 분석합니다. 전송에 다시 동의한 뒤 실행하세요. 점수·인용된 문장·판단 이유가 두 카드에 표시됩니다.
5. 수정본을 복사하거나 TXT/검수 JSON을 저장합니다. JSON에는 원문·수정본·수정량·완료한 문체 평가가 들어갑니다. 원문만 분석한 경우에도 검수 JSON을 저장할 수 있습니다.
6. 화면의 **앱 종료**로 종료합니다. 브라우저 탭만 닫으면 앱은 계속 실행됩니다.

같은 앱을 다시 실행하면 기존 화면을 엽니다. 포트는 자동 선택합니다. 글을 자동으로 디스크에 저장하지 않으므로 종료 전에 필요한 결과를 저장하세요. 상태 파일은 `%LOCALAPPDATA%\ClearWrite\runtime`에 생성됩니다. `instance.json`은 PID·포트·버전만 포함하고, `startup.log`에는 시작 정보나 정제된 시작 오류를 남깁니다. 브라우저가 열리지 않으면 상태 파일의 `url`을 확인하세요.

```powershell
ClearWrite.exe --no-open
ClearWrite.exe --shutdown
ClearWrite.exe --port 18766
```

소스 사용은 Python 3.10+에서 `python scripts/desktop_entry.py` 또는 `python rewrite.py`로 시작합니다. `--state-dir <별도 폴더>`로 개발 인스턴스를 분리할 수 있습니다. 0.1.x의 고정 기본 포트가 0(자동)으로 바뀌었으므로 고정 주소가 필요한 자동화는 `clearwrite serve --port 8765`처럼 명시하세요.

## Codex·Claude 준비

각 사용자 PC의 [Codex CLI](https://developers.openai.com/codex/cli/) 또는 [Claude Code CLI](https://code.claude.com/docs/en/overview) 설치와 해당 CLI의 로그인이 필요합니다. 데스크톱 앱 로그인만으로 CLI가 준비되지는 않습니다. 먼저 터미널에서 `codex --version` 또는 `claude --version`과 그 도구의 로그인 절차를 확인하세요. 앱은 모델·CLI를 자동 설치하지 않습니다.

현재 채팅을 재개하거나 그 답변을 가져오는 기능은 아닙니다. **별도의 새 모델 요청**이며 OpenAI/Anthropic으로 글을 보내고 계정 사용량이 소모됩니다. 매번 전송 동의가 필요합니다. 실패 시 사용자 허락 없이 다른 유료 모델로 전환하지 않습니다.

ClearWrite는 버전·도움말·Codex 기능 목록을 로컬에서 확인하고 필요한 옵션이 없으면 업데이트 필요로 표시합니다. Codex CLI **0.147.0**(0.3.1 시점)과 Claude Code **2.1.304**(0.4.0, Windows)의 실제 응답 처리를 확인했습니다. 0.3.x의 Claude 연결은 구독 로그인에서 항상 실패했으며 0.4.0에서 고쳤습니다. CLI 설치/업데이트 후 앱을 다시 시작하세요.

Windows는 PATH와 npm의 Codex 네이티브 실행 파일, Claude 기본 네이티브 경로, 설치된 Node+Claude cli.js를 탐색합니다. 자동 탐색이 안 되면 `CLEARWRITE_CODEX_PATH` 또는 `CLEARWRITE_CLAUDE_PATH`에 신뢰하는 실행 파일의 절대 경로를 설정할 수 있습니다. `.cmd/.bat/.ps1` 셸 래퍼는 실행하지 않습니다. macOS/Linux는 PATH를 사용하며 이번 네이티브 실행은 미검증입니다.

로그인 파일은 ClearWrite가 읽거나 복사하지 않습니다. 상속된 `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` 등의 토큰을 모델 자식 프로세스에 넘기지 않고, CLI 자체의 저장된 로그인을 사용합니다. CLI의 보관·캐시·과금 정책은 해당 도구에 적용됩니다. 모델 이름을 비우면 CLI 기본 모델이며, 사용자 config와 프로젝트 지침은 편집 작업에 그대로 불러오지 않습니다.

## 편집·AI 문체 평가

원문 최대 12,000자. 모델은 정확한 원문/대체문/이유를 반환합니다. 모호한 위치, 숫자·인용·조건 변경, 과도한 축약을 검사한 뒤 실제 적용된 구간만 칠합니다. 검사가 모든 의미 변화를 잡지는 않으므로 마지막 대조가 필요합니다. 원문을 수정하면 이전 결과 저장은 비활성화됩니다. 요청 취소가 이미 사용한 서버 사용량까지 환불하지는 않습니다.

**예시 체험**은 저장된 편집 제안을 실제 엔진으로 적용하며 모델 요청이 없습니다. **로컬 규칙 분석**, **원문 보존**도 모델을 호출하지 않습니다. 화면의 Ollama/규칙 윤문 선택지는 제거했으며 기존 CLI 자동화 호환성을 위해 `builtin`과 `ollama` 백엔드는 남겨 두었습니다.

**AI 문체 분석**은 Codex·Claude CLI를 사용합니다. 별도 탐지기 키는 필요 없습니다. 원문만 또는 원문과 현재 수정본을 함께 보내며, 버튼을 한 번 누르면 CLI를 한 번 실행합니다. 동일한 글의 전후 점수는 같은 평가를 재사용합니다. 윤문을 다시 실행하지 않으며 분석 실패나 취소로 수정본을 잃지 않습니다.

반복, 상투적 표현, 획일적 흐름, 추상적 부연을 각 0~25점으로 평가해 합산합니다. 높은 점수는 문체 특징이 두드러진다는 뜻이며 **AI 작성 확률·작성률이나 저자 판정이 아닙니다.** 모델이 제시한 실제 인용 문장과 판단 이유, 항목별 점수도 표시합니다. 인용이나 해시가 맞지 않으면 **미분석**으로 유지합니다. 점수의 정확도·일관성·한국어 저자 판별력은 검증하지 않았습니다.

**실제 수정 비율**은 실제 적용된 글자 diff로 `(삭제·교체된 원문 글자 + 추가·대체된 글자) / (원문 + 수정본 글자 수) × 100`을 계산합니다. 공백을 포함하고 글자 수는 Unicode 코드포인트 기준입니다. 원문 유지·차단은 0%입니다. 원문을 바꾸면 과거 점수와 비율이 지워지며 이전 작업의 응답은 무시합니다. 저장하는 JSON에 문체 평가와 글자 수·계산식을 포함합니다.

Pangram 연결과 API 키 설정은 0.3.0에서 제거했습니다. 이전 CLI의 `--provider pangram`, `--detector`, `--allow-external`은 더 이상 지원하지 않습니다. CLI에서는 `detect input.txt --provider codex --candidate result.txt --allow-model`을 사용하세요. 기존 저장 파일·CLI 로그인·전역 설정·설치된 스킬은 자동 변경하지 않습니다.

## 배포 범위

한 사람이 자기 PC에서 쓰는 도구입니다. 인터넷 공개 서버나 여러 사람의 계정을 받는 SaaS로 배포하는 형태는 아닙니다. ZIP을 받아도 각자 CLI와 로그인이 필요합니다. 이번 Windows 빌드는 서명 전 개발 릴리스이며 서명·자동 업데이트·탐지 서비스 계정·호스팅은 포함하지 않습니다. OS 경고 우회나 백신 해제를 요구하지 않습니다. 실행 파일에는 개인 글·계정·키·모델 CLI를 포함하지 않습니다.

## 0.4.0 페르소나와 문법 스타일

**편집자 페르소나**는 개입 강도를 정합니다. 꼼꼼한 교정자(가볍게, 맞춤법·띄어쓰기 위주), 담백한 편집자(기본), 격식 있는 보고자, 칼럼니스트·쉬운 말 해설가·다정한 안내자(적극적으로) 중에서 고릅니다. 강할수록 허용 변경량이 크고(15% → 35% → 50%), 적극적인 페르소나는 검사에 걸린 제안만 빼고 나머지를 적용합니다.

**문법 스타일**은 페르소나와 따로 고르며 한국어 종결어미를 합니다체·해요체·한다체로 통일합니다. '페르소나 기본값'이면 격식 있는 보고자는 합니다체, 다정한 안내자는 해요체, 나머지는 원문 유지입니다. 결과 아래에 목표 어미로 끝난 문장 비율이 표시됩니다. 문장 끝 어미만 세는 규칙 판정이며 인용·코드·제목은 세지 않습니다.

어느 페르소나·스타일이든 숫자·부정·조건·인용 보존 검사는 똑같이 적용되고, 새 사실을 더하지 않습니다. `In conclusion`, `결론적으로` 같은 상투구를 지운 부분은 과도한 축약으로 세지 않습니다.

## 0.3.1 개인정보 처리와 업데이트

ClearWrite가 원문·응답·오류 내용을 임시 파일에 쓰지 않도록 바꿨습니다. 메모리 파이프로 주고받고, 임시 작업 폴더에는 글이 들어 있지 않은 응답 형식 파일만 둡니다. 강제 종료로 폴더가 남더라도 새 요청의 원문·응답 파일은 생성되지 않습니다. CLI 자체의 캐시·서비스 보관, 구버전이 이미 남긴 파일과 사용자가 저장한 TXT·JSON은 별도입니다.

서버의 완료·실패·취소 기록은 작업 완료 후 15분이 지나면 새 요청 없이도 자동으로 지웁니다. 조회 시에도 만료를 확인하고 앱 종료 시 기록을 비웁니다. 편집 화면에 열어 둔 글과 저장 파일은 지우지 않습니다.

업데이트할 때는 기존 앱에서 필요한 결과를 저장하고 **앱 종료**를 누르세요. 새 ZIP 전체를 별도 폴더에 푼 뒤 그 안의 실행 파일을 실행합니다. 구버전이 실행 중인 채 새 버전을 열면 기존 화면으로 돌아갈 수 있으므로 먼저 종료해야 합니다.
