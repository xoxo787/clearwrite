# 0.2.1 수정 위치 동기화 계약

기존 종이/형광펜 UI와 비교 3영역을 유지한다. 목표는 수정 1개를 선택했을 때 원문·수정본·이유를 모두 찾을 수 있게 하는 것이다. 대상 크기는 1440x900 및 390x844다.

- 클릭, 이유 카드, 이전/다음, Enter/Space가 같은 선택 ID를 세 영역에 적용한다.
- 각 영역 내부를 선택 지점 중심으로 이동한다. 가로 3열에서는 비교 영역이 뷰포트 밖에 걸리면 영역 전체를 한 번 맞춘다. 다른 영역을 맞추느라 문서 페이지가 왕복 이동하지 않는다.
- 공백 추가처럼 원문에서 없던 내용은 빈 문자열인 추가 위치 표식을 둔다. 삭제 후에도 수정본에 위치 표식을 둔다. 표시 세그먼트를 합친 텍스트는 전후 실제 글과 정확히 같아야 한다.
- 원문 편집 중 기존 결과의 수정을 선택하면 변경 표시로 돌아온다. 바뀐 원문의 오래된 결과는 기존 규칙대로 선택/저장을 차단한다.
- 모바일은 세 영역을 세로 배치하므로 한 화면에 전부 넣지는 않는다. 내부 선택과 위치는 함께 맞추되, 선택 때문에 문서 전체가 여러 번 이동하지 않아야 한다.
- reduced-motion 설정이면 부드러운 스크롤을 사용하지 않는다. 위치 표식에는 추가/삭제 레이블과 키보드 조작을 제공한다.

상태는 기존 empty/loading/error/partial/permission을 유지한다. success에서 긴 글, 순수 추가/부분 삭제, 원문 편집 토글 및 빠른 선택 이동을 검증한다. 실제 Codex의 저장된 검수 결과는 외부 전송 없는 테스트 서버에서 재생하며 새 실호출로 소개하지 않는다.
