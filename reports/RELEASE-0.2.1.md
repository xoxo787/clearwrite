# ClearWrite 0.3.0 수정과 검증

2026-10-17, Windows x64 / Python 3.13.14에서 검증한 자동스크롤 수정 릴리스입니다.

## 바뀐 동작

수정 구간, 이유 카드, 이전/다음 버튼, Enter/Space로 수정 하나를 선택하면 원문·수정본·이유가 함께 해당 위치로 이동합니다. 가로 3열에서는 비교 영역이 화면 아래에 걸려 있을 때 영역 전체를 한 번 맞춰 선택한 내용을 함께 볼 수 있게 합니다. 모바일은 세로 배치이며 각 영역 내부 위치를 동기화합니다.

추가만 있는 편집은 원문에 추가 위치 표식, 부분/전체 삭제는 수정본에 삭제 위치 표식을 만듭니다. 표식은 빈 문자열과 CSS 레이블로 표현해 실제 원문/수정본·복사·다운로드에 레이블을 섞지 않습니다. 원문 편집 상태에서 기존 수정을 선택하면 변경 표시로 돌아옵니다. 원문을 실제로 바꾼 경우의 오래된 결과 차단은 유지합니다.

## 주요 변경 파일

- `src/clearwrite/web/app.js`: 세 영역 내부 스크롤, 데스크톱 비교 영역 맞춤, 편집 보기 복귀, 위치 표식 렌더링.
- `src/clearwrite/web/app.css`: 추가/삭제 위치 표식과 공백 기호.
- `src/clearwrite/comparison.py`: insert/delete opcode의 텍스트를 바꾸지 않는 위치 표식.
- `tests/test_editor.py`: 이모지 앞뒤 공백 삽입 위치와 부분 삭제의 표시·원문 재구성 회귀 검사.
- `tests/fixtures/serve_ui_fixture.py`: 저장된 검수 계획을 외부 요청 없이 재생하는 브라우저 QA 옵션.
- 패키지·스킬·플러그인 버전 0.3.0, 문서와 자동 생성 번들 동기화.

`core.py`와 모델 호출 코드는 0.2.0과 동일합니다. 검수 JSON 필드는 유지하며 표시용 kind에 `insertion_marker`를 추가하고 `deletion_marker` 범위를 부분 삭제로 확장했습니다. 두 표식의 text는 빈 문자열입니다. 기존 텍스트/편집 계획에는 마이그레이션이 필요하지 않습니다.

## 실제 실행한 검사

- unittest 199개: 197개 통과, 실패/오류 0, 심볼릭 링크 생성 불가로 2개 건너뜀.
- 변경된 Python 비교 모듈의 집중 커버리지 97%. 전체 프로그램 커버리지 수치로 소개하지 않습니다.
- 변경 Python/테스트 Ruff, JavaScript 문법, Python compileall 통과. 별도 정적 타입 검사기는 구성되어 있지 않아 미실행입니다.
- 기존 20개 자료 벤치마크를 오프라인으로 재현했습니다. 의미 동등성·독자 피로 감소·모델 품질을 증명하는 검사는 아닙니다.
- 1440x900에서 저장된 실제 모델 계획을 재생해 수정 1/2/3, 원문 표식의 Enter, 원문 편집 상태의 이유 선택을 확인했습니다. 각 선택의 원문·수정본·이유 대상이 영역과 뷰포트 안에 함께 존재했습니다. 원문을 수동으로 스크롤하지 않았습니다.
- 390x844에서 세로 배치와 내부 위치 동기화, 가로 넘침 없음을 확인했습니다. 모바일에서 세 영역 전체가 한 뷰포트에 들어간다고 주장하지 않습니다.
- 긴 글의 부분 삭제 위치, 원문/결과 DOM 전체와 검수 데이터 일치, 위치 레이블이 글에 섞이지 않음을 확인했습니다. empty/loading/error/partial/permission도 명시적인 오프라인 응답으로 확인했습니다.
- Windows portable EXE 직접 실행, 웹 리소스 포함, 네트워크 모델 요청 없는 CLI 탐색/예시, 단일 인스턴스 재사용, 정상 종료를 확인했습니다.
- wheel을 새 가상 환경에 네트워크 없이 설치해 CLI 분석을 확인했습니다.

이번 수정 검증은 저장된 결과의 재생이며 추가 모델 호출·탐지 서비스 호출은 0회입니다. 개인 글과 개인 검증 화면은 배포 ZIP/소스에 포함하지 않습니다. 배포물은 미서명 개발 빌드이며 공개 업로드는 수행하지 않았습니다. Claude·외부 탐지기·macOS/Linux 실사용 검증 범위는 이전 릴리스의 한계를 그대로 따릅니다.
