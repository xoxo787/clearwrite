# 0.2.0 릴리스 검증 범위

2026-10-17, Windows x64 / Python 3.13.14에서 확인했습니다. 개발 패키지이며 공개 업로드·코드 서명은 수행하지 않았습니다.

- 전체 unittest: 197개 실행, 195개 통과, 2개 건너뜀. 건너뛴 항목은 이 호스트에서 심볼릭 링크 생성이 불가능한 설치/출력 검사입니다.
- 새 모델/비교/작업/데스크톱 모듈과 관련 테스트·빌드 스크립트 Ruff 통과. JavaScript 문법 검사와 Python compileall 통과. 별도 정적 타입 검사기는 구성하지 않았습니다.
- 기존 20개 자료의 오프라인 벤치마크 재현. 편집 엔진 core.py는 0.1.1 원본과 동일합니다. 실시간 모델 품질 비교나 독자 실험이 아닙니다.
- wheel: 새 가상 환경에서 네트워크 없이 설치하고 CLI 분석 실행을 확인했습니다.
- 실제 Windows portable EXE: 직접 실행, 자동 포트, HTML/CSS/JS 포함, 모델 호출 없는 연결 탐색/예시, 중복 실행 재사용, 종료 및 상태 정리를 확인했습니다. 최초 빌드의 웹 리소스 누락은 수정 후 다시 빌드·검사했습니다.
- 브라우저: 1440×900과 390×844 화면, 연결된 수정 표시/이유, 키보드 선택, 원문 변경 시 저장 차단, 요청 동의, 오류/취소/외부 검사 실패 상태를 확인했습니다. 오류·외부 실패는 OFFLINE UI TEST 배너가 있는 명시적 모의 서버이며 외부 요청이 없습니다.
- Codex CLI 0.147.0: 사용자 승인 후 비개인 테스트 예문 144자에 **한 번** 실제 요청했습니다. 유효한 수정 없음 응답을 받아 보존 검사와 UI 처리를 확인했습니다. 수정 예시 화면은 별도의 저장된 제안을 실제 엔진으로 적용한 것이며 실호출 결과로 소개하지 않습니다.
- Claude Code CLI: 이 PC에 미설치. fake child process 기반 JSON/UTF-8/취소/시간 초과 계약 테스트만 수행했습니다. 실제 호출은 미검증입니다.
- Pangram: 키 미설정, 실제 API 호출 없음. 계약 테스트와 실패 처리만 확인했습니다. 한국어 판독 정확도는 미검증입니다.
- Windows 실행 파일은 NotSigned입니다. macOS/Linux 네이티브 실행 파일과 호스트 CI는 이번에 검증하지 않았습니다.

`core.py` 보존 검사는 의미 동등성을 증명하지 않으며 문체 점수는 AI 확률이 아닙니다. 실제 탐지 값이 없으면 미측정으로 남깁니다. 일반 사용자 배포에도 별도의 Codex/Claude CLI와 로그인이 필요합니다. 기존 설치 플러그인 0.1.1은 이 패키지 생성 과정에서 교체하지 않았습니다.
